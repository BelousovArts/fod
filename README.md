# Система обнаружения посторонних объектов для беспилотных поездов в тоннеле метро по данным 3D-лидара

Команда **Attention Please** (Пермь): Белоусов Артём, Белоусова Надежда · belousov.arts@yandex.ru

По облаку лидара (ROS 2, `sensor_msgs/PointCloud2`) находит путь и габарит поезда и
в каждом кадре сообщает: **СВОБОДНО**, **ВНИМАНИЕ**, **ПРЕПЯТСТВИЕ** (расстояние и список
объектов) или **НЕ ГОТОВ** (путь ещё не найден). Габарит проверяется до 150 м.

![Человек на пути в 56 м](docs/figures/person.png)

## Быстрый старт

Нужны Docker, видеокарта NVIDIA с драйвером ≥ 570 и
[nvidia-container-toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html).

```bash
# 1. Собрать образ (один раз, ~10 мин, ~20 ГБ места)
docker build -t fod -f docker/Dockerfile .

# 2. Прогнать запись → results/<имя записи>/
./run_bag.sh /путь/к/записи --video

# 3. Посмотреть прогон в 3D (rerun): облако, габарит, препятствия, графики
./run_tool.sh rerun /путь/к/записи
rerun results/<имя записи>/rerun.rrd      # просмотрщик: pip install rerun-sdk==0.22.1

# 4. Живой режим с RViz (запись по кругу или настоящий лидар)
docker build -t fod-viz --target viz -f docker/Dockerfile .
./run_live.sh /путь/к/записи
./run_live.sh --topic /lidar_points
```

Запись — папка с `metadata.yaml` (sqlite3 или mcap). Топик облака находится сам,
задать явно — `--topic`.

## Что на выходе

**Офлайн** (`results/<запись>/`):

| Файл | Что внутри |
|---|---|
| `detections.csv` | по кадру: статус, расстояние до ближайшего препятствия, докуда виден путь, скорость, время обработки |
| `obstacles.csv` | подтверждённые препятствия: расстояние вдоль пути, смещение от оси, высота, координаты, с какого расстояния замечено |
| `summary.json` | итог записи: кадры по статусам, каждое препятствие, время на кадр |
| `video.mp4` | с `--video`: вид спереди, вид сверху, панель скорости и препятствий |

**Живой узел** (топики ROS 2):

- `/fod/status` — JSON: статус, расстояние, препятствия и подозрения, докуда виден путь,
  скорость, рекомендуемая скорость, тормозной путь, задержка;
- `/fod/obstacles` — `PointCloud2`, точка на объект: `distance`, `offset`, `height`,
  `track_id`, `confirmed`, `first_seen`. Пустое облако — путь свободен или не готов;
- `/fod/markers` — ось, габарит и объекты для RViz.

## На поезде

Служба с автозапуском; параметры в `config/train.yaml` (топик, установка лидара, GPU).

```bash
ROS_DOMAIN_ID=5 FOD_UID=$(id -u) FOD_GID=$(id -g) docker compose up -d --build
docker compose logs -f fod
```

`FOD_UID` / `FOD_GID` — тот же пользователь, что у драйвера лидара: иначе общая память DDS
недоступна и облака не доходят.

**Установка лидара.** По умолчанию вперёд — ось −y, вверх — +z. Иначе — `forward`, `up`, `rpy`
в `config/train.yaml` или ключи `--forward` / `--up` / `--rpy`.

**Если узел не успевает**, он берёт самый свежий кадр и пропускает старые: отставание не копится.

## Инструменты

Работают на том же детекторе, что и узел. Результат — в `results/<запись>/`.

| Команда | Что делает |
|---|---|
| `./run_tool.sh video <запись>` | видео и CSV |
| `./run_tool.sh rerun <запись>` | 3D-просмотр в rerun: облако, габарит, карта, графики |
| `./run_tool.sh map <запись>` | карта записи: облако в мире, вид сверху плитками по 100 м, траектория |
| `./run_tool.sh stand <запись> --object person@80 --video` | вставить объект в запись и узнать, с какого расстояния он обнаружен |

Без Docker: `FOD_NO_DOCKER=1`.

## Как это работает

1. **Одометрия** — своя: сдвиг текстуры стен тоннеля между кадрами, затем уточнение small_gicp.
2. **Рельсы вблизи** — нейросеть по развёртке лидара и шаблон пары головок.
3. **Путь вдали** — контактный рельс, профиль тоннеля и вторая нейросеть по накопленному виду
   сверху; ось хранится в мировых координатах.
4. **Габарит 2,1 × 3 м и норма полотна**; всё, что выше нормы внутри габарита и держится
   4 кадра из 5, — препятствие.

## Результаты

Стенд: объекты вставлены по лучам лидара в настоящие записи, поезд подъезжает к ним
(медианы по 11 подъездам на объект).

| Что | Результат |
|---|---|
| Человек на пути | ВНИМАНИЕ с 137 м, подтверждён со 114 м |
| Щит 2 × 1,9 м | подтверждён со 129 м |
| Ящик 0,5 м / куб 0,3 м | подтверждены с 85 м / с 70 м |
| Ложные тревоги на чистых записях | 0 за 22 минуты |
| Настоящие человек и предмет 16 см на рельсе (`doubleT_obstacle`) | оба подтверждены на 56 м |

Время на кадр: 75–90 мс на RTX 5080 Laptop (лидар — 10 Гц).

## Ограничения

- Габарит ±1,05 м от оси: предметы у стены и на краю платформы не проверяются.
- Сети обучены на тоннелях из этих записей; где они не уверены, путь проверяется ближе.
- Плоские предметы ниже 6 см над головками, лежащие между рельсами, не проверяются —
  так отсекаются таблички и крепления на полотне.
